# weather-mcp

An [MCP (Model Context Protocol)](https://modelcontextprotocol.io) server that provides weather data to LLM clients such as Claude Desktop, using the [U.S. National Weather Service (NWS) API](https://www.weather.gov/documentation/services-web-api).

Based on the official MCP tutorial: [Build an MCP server](https://modelcontextprotocol.io/docs/2026-07-28/develop/build-server).

## Data source

Weather data comes from the public NWS API at `https://api.weather.gov`:

- Free to use, no API key required.
- Covers locations in the United States only.
- NWS requires every request to include a `User-Agent` header that identifies the application.

## Tech stack

- [TypeScript](https://www.typescriptlang.org/)
- [`@modelcontextprotocol/server`](https://www.npmjs.com/package/@modelcontextprotocol/server) — MCP server SDK
- [`zod`](https://zod.dev/) — input schema validation

## Requirements

- [Node.js](https://nodejs.org/) (current LTS recommended) and npm

## Installation

```bash
git clone <repository-url>
cd weather-mcp
npm install
```

## Build

```bash
npm run build
```

The TypeScript sources from `src/` are compiled into `build/`, and `build/index.js` is made executable.

> **Windows note:** the build script uses `chmod`, which is not available in `cmd.exe` or PowerShell. Run the build from Git Bash or WSL, or run `npx tsc` directly.

## Usage with Claude Desktop

1. Build the server (see [Build](#build)).
2. Open the Claude Desktop configuration file (create it if it does not exist):
   - macOS: `~/Library/Application Support/Claude/claude_desktop_config.json`
   - Windows: `%APPDATA%\Claude\claude_desktop_config.json`
3. Add the server under the `mcpServers` key. If the file already lists other servers, add `weather` next to them instead of replacing the whole object.

   macOS / Linux:

   ```json
   {
     "mcpServers": {
       "weather": {
         "command": "node",
         "args": ["/ABSOLUTE/PATH/TO/weather-mcp/build/index.js"]
       }
     }
   }
   ```

   Windows (backslashes must be escaped in JSON):

   ```json
   {
     "mcpServers": {
       "weather": {
         "command": "node",
         "args": ["C:\\ABSOLUTE\\PATH\\TO\\weather-mcp\\build\\index.js"]
       }
     }
   }
   ```

   The path must be absolute.
4. Fully restart Claude Desktop. Closing the window is not enough, because the app keeps running in the system tray / menu bar. Quit it from there and start it again.
5. Check that the `weather` server and its `get_alerts` and `get_forecast` tools appear in the list of connected tools.

### Example prompts

The NWS API covers U.S. locations only.

- "What are the active weather alerts in Texas?"
- "What's the weather forecast for Sacramento?"

Claude asks for permission before calling a tool. Approve the request to let it fetch the data.

### Troubleshooting

- Claude Desktop writes MCP server logs to `~/Library/Logs/Claude/` on macOS and `%APPDATA%\Claude\logs\` on Windows (`mcp*.log` files).
- After changing the code, run `npm run build` again and restart Claude Desktop.
- The server logs to stderr only. Writing to stdout (for example with `console.log`) corrupts the stdio protocol stream.

## Project structure

```
weather-mcp/
├── src/
│   ├── index.ts                     # Entry point: starts the server over stdio
│   ├── server.ts                    # Creates the MCP server and registers tools
│   ├── config.ts                    # NWS API base URL and User-Agent
│   ├── types.ts                     # NWS API response interfaces
│   ├── schemas.ts                   # Zod input schemas for tools
│   ├── helpers/
│   │   ├── nws-client.ts            # NWS API request helper
│   │   ├── formatters.ts            # Alert and forecast formatting
│   │   └── tool-result.ts           # Tool result builder
│   └── controllers/
│       ├── alerts.controller.ts     # get_alerts tool handler
│       └── forecast.controller.ts   # get_forecast tool handler
├── docs/
│   └── plans/                       # Implementation plans
├── build/                           # Compiled output (generated by `npm run build`)
├── package.json
└── tsconfig.json
```
